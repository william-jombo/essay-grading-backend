# SentenceTransformer

This is a [sentence-transformers](https://www.SBERT.net) model trained. It maps sentences & paragraphs to a 384-dimensional dense vector space and can be used for semantic textual similarity, semantic search, paraphrase mining, text classification, clustering, and more.

```
SentenceTransformer(

  (1): Pooling({'word_embedding_dimension': 384, 'pooling_mode_cls_token': False, 'pooling_mode_mean_tokens': True, 'pooling_mode_max_tokens': False, 'pooling_mode_mean_sqrt_len_tokens': False, 'pooling_mode_weightedmean_tokens': False, 'pooling_mode_lasttoken': False, 'include_prompt': True})
  (2): Normalize()
)
```

## Usage

### Direct Usage (Sentence Transformers)

First install the Sentence Transformers library:

```bash
pip install -U sentence-transformers
```

Then you can load this model and run inference.
```python
from sentence_transformers import SentenceTransformer

# Download from the 🤗 Hub
model = SentenceTransformer("sentence_transformers_model_id")
# Run inference
sentences = [
    'com 542. com 542. write a five page essay on why java is the basic language learned for most basic beginners',
    'Java is used by beginners because it is easy to learn. It has classes and objects. You can run Java on any computer using the JVM. Java is used in Android development. Many universities teach Java first.',
    'Climate change is affecting Malawi through droughts, floods and rising temperatures. Malawi depends on rain for farming so unpredictable weather causes food shortages. The country also loses forests due to deforestation which makes climate change worse. Government programmes exist but resources are limited. Communities need education on climate adaptation strategies such as irrigation and drought resistant crops.',
]
embeddings = model.encode(sentences)
print(embeddings.shape)
# [3, 384]

# Get the similarity scores for the embeddings
similarities = model.similarity(embeddings, embeddings)
print(similarities)
# tensor([[1.0000, 0.3394, 0.1084],
#         [0.3394, 1.0000, 0.0777],
#         [0.1084, 0.0777, 1.0000]])
```
